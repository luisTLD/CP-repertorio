# CP-repertorio

Repertório de questões resolvidas de programação competitiva, em Python.

- [`resolvidos.md`](resolvidos.md): a lista de todos os problemas aceitos, com link, juiz e técnica usada.
- [`solucoes/`](solucoes): um arquivo por problema, separado por juiz (`atcoder/`, `cses/`, `leetcode/`). As duas primeiras linhas de cada arquivo são o nome e o link do problema.
